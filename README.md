# GlobalWork - Website Xuất Khẩu Lao Động

Website chuyên về dịch vụ xuất khẩu lao động, hỗ trợ lao động Việt Nam tìm việc làm tại nước ngoài.

## 🌟 Tính Năng

- Trang chủ với carousel và giới thiệu
- Trang về chúng tôi
- Dịch vụ xuất khẩu lao động
- Đội ngũ tư vấn chuyên nghiệp
- Phản hồi từ khách hàng
- Thư viện ảnh
- Liên hệ

## 🚀 Công Nghệ Sử Dụng

- HTML5
- CSS3
- JavaScript (jQuery)
- Bootstrap 5
- Font Awesome
- Owl Carousel
- WOW.js (Animations)
- Lightbox

## 📁 Cấu Trúc Thư Mục

## 🛠️ Cài Đặt & Chạy Local

1. Clone repository:
```bash
git clone https://github.com/yourusername/globalwork-website.git
cd globalwork-website
```

2. Chạy local server:
```bash
# Sử dụng Python
python -m http.server 8000

# Hoặc sử dụng Node.js
npx serve -p 8000
```

3. Mở trình duyệt: `http://localhost:8000`

## 📦 Deploy
